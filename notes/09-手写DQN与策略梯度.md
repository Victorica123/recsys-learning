# 09 · 手写 DQN 与策略梯度：一次完整的"失败 → 诊断 → 修复"实战

> Phase 2 · 模块 2。任务：在推荐会话 MDP 上训练 RL 智能体，验证
> "长期收益优化 > 短视贪心"。这是本项目最有研究生味道的一段——
> 第一次训练彻底失败，而失败本身成了最好的教材。

## 1. 环境设计（RecSimEnv v2）

- **用户模型**：冻结的 SASRec（checkpoints/sasrec_main.pt），对 Top200
  热门物品打分 → sigmoid 得到即时喜欢概率
- **状态**（83 维）：SASRec 上下文向量(64) + 最近 5 次推荐的类型直方图(18)
  + 连续无感计数(1)
- **动作**：200 个候选物品（离散）
- **奖励**：喜欢 +0.9 / 无感 −0.1；会话 20 步
- **两个长期动力学**（RL 存在的意义）：
  - 疲劳：连续同类型推荐，喜欢概率 ×0.75^n（换类型即恢复）
  - 厌倦退出：连续 3 次无感 → 会话提前终止（失去未来所有奖励）

设计要点：首版环境疲劳按"会话累计次数"惩罚，贪心几乎不受影响，
**可学习信号太弱**——环境本身也要做"信号工程"。

## 2. DQN v1 为什么发散（致命三要素现场）

现象：Q 值在训练中爆炸到 195~549（理论上限 ≈ Σ0.9^t×0.9 ≈ 9），
评估 4.12 < 随机 7.21 < 贪心 9.43。

Sutton 的**致命三要素**同时成立：函数逼近 + 自举(bootstrap) + 离策略。
具体机制：

1. max 算子对 200 个带噪声的 Q 估计取最大值 → 每次备份注入正偏差
2. **Polyak 软更新（τ=0.005）让在线网和目标网几乎相等** →
   Double DQN 的"选动作/估值分离"去偏机制形同虚设
3. 单步 4 次梯度更新 × 有限回放缓冲 → 同一条样本被反复过拟合，
   过估计被逐轮放大

## 3. v2 修复（每刀都对应一个病因）

| 修复 | 对应病因 |
|------|----------|
| 硬目标同步（每 500 次更新整体拷贝） | 让 Double DQN 两网去相关，去偏生效 |
| LayerNorm + lr 3e-4→1e-4 | 压值函数尺度漂移 |
| 每环境步仅 1 次梯度更新 | 降过拟合/过估计放大 |
| 环境改为连续疲劳 + 厌倦退出 | 提供可学习的长期信号 |

结果：Q 平稳爬升 0.01→5.14（上限≈9），评估 **7.63 > 随机 6.69 >> 贪心 2.81**。
证据：`experiments/dqn_v1_log.csv` vs `dqn_v2_log.csv` → `figures/12-DQN稳定性对比.png`。

## 4. 策略梯度：绕开自举的另一条路

REINFORCE + Actor-Critic：**不 bootstrap**，用完整回合的真实回报 G_t
减去学习基线 V(s) 当优势，沿 log π(a|s) 上升。300 次更新（约 3 分钟）：

| 策略 | 会话奖励 | 会话长度 | 类型多样性 |
|------|---------|---------|-----------|
| 贪心(短视) | 2.81 | 7.7 | 1.00 |
| 策略梯度(argmax 部署) | 5.07 | 10.5 | 1.76 |
| 随机 | 6.69 | 13.2 | 4.78 |
| Double DQN(确定性) | 7.63 | 13.7 | 4.08 |
| **策略梯度(采样部署)** | **15.86** | **19.5** | **5.42** |
| **贪心去重(跳过同类型)** | **17.93** | **20.0** | **2.42** |

**本课题最重要的发现**：这个环境的最优策略本质上是随机的——必须交错
类型才能规避疲劳。训练时采样拿到 15.86 的策略，argmax 部署直接掉到
5.07；熵退火（0.01→0.002 续训 100 次）只能补救一部分。
→ RL 模型上线时，"确定性部署还是采样部署"是一个被严重低估的决策。

**公平核对（重要修正）**：补了一个"贪心去重"基线——仍短视取最高分，但
跳过与上一步相同的类型。它直接拿到 **17.93**，超过 DQN 7.63 与策略梯度
15.86。也就是说，手写疲劳奖励（0.75^n）让"交错类型"这个朴素启发几乎
免费达成最优，**RL 智能体在本仿真器上并没有带来增量**。之前"5.6 倍于
贪心"对比的是一个每步都推同一部电影的稻草人贪心。
教训：RL 实验必须先有公平的启发式基线，否则"RL 赢了"可能是"基线太弱"。

## 5. 面试速记

- Q：DQN 为什么会发散？A：致命三要素 + max 过估计；讲清 Double DQN
  依赖"两网去相关"，软更新会破坏它 → 硬目标同步
- Q：价值方法 vs 策略梯度？A：DQN 学确定性 argmax 策略（样本高效但怕
  自举）；PG 直接学分布（无自举稳但方差大）→ Actor-Critic 压方差
  → PPO 再加重要性采样比裁剪复用数据
- Q：推荐为什么需要 RL？A：疲劳/留存是跨步效应，贪心只优化即时 CTR；
  本环境量化了短视的代价（2.81 vs 15.86），但也诚实记录：贪心去重基线
  17.93 说明该结论依赖手写奖励，真实推荐要先拿启发式基线校准
