## 1. 基础概念（一切的起点）

### MDP 五元组 (S, A, P, R, γ)
- **S** 状态：LunarLander 的 8 维观测；推荐里=用户最近交互序列
- **A** 动作：4 个推进器；推荐里=推哪个物品
- **P** 状态转移概率：环境物理规律；推荐里=用户心理状态怎么变（不可知，只能仿真）
- **R** 奖励：着陆+100；推荐里=点击/留存
- **γ** 折扣因子：0.9~0.999。γ 越小越"短视"，越大越看重长期

### 核心量
- **回报 G_t** = Σ γ^k r_{t+k+1}（折扣累积奖励，不是单步奖励！）
- **状态价值 V^π(s)**：在 s 出发按策略 π 行动的期望回报
- **动作价值 Q^π(s,a)**：在 s 做 a 后再按 π 行动的期望回报
- **优势 A(s,a) = Q(s,a) - V(s)**：这个动作比平均水平好多少（PPO/GRPO 的核心）

### Bellman 方程（面试必考）
```
V*(s) = max_a [ r(s,a) + γ Σ P(s'|s,a) V*(s') ]
Q*(s,a) = r(s,a) + γ Σ P(s'|s,a) max_a' Q*(s',a')
```
一句话：**最优价值 = 即时奖励 + 折扣后的下一步最优价值**（递归定义）。

### On-policy vs Off-policy（高频考点）
- **On-policy**：训练数据必须来自当前策略（PPO、GRPO、SARSA）
  → 样本效率低，但稳定
- **Off-policy**：可以用旧策略/别人的数据训练（DQN）
  → 样本效率高（replay buffer），但分布偏移会不稳

## 2. 价值方法（Value-based）

### Q-learning（off-policy 的 TD 控制）
```
Q(s,a) ← Q(s,a) + α [ r + γ max_a' Q(s',a') − Q(s,a) ]
                      \______ TD 目标 ______/  \_ TD 误差 _/
```
SARSA 的区别：TD 目标里用**实际采取的** a'（on-policy），不是 max。

### DQN（Nature 2015，论文[7]）两大稳定器
1. **经验回放（Replay Buffer）**：存 (s,a,r,s') 池子随机抽 batch
   → 打破样本相关性、数据复用
2. **目标网络（Target Network）**：TD 目标里的 Q 用一份延迟更新的
   参数副本 → 防止"自己追自己"的发散

### DQN 变种（面试加分项）
- **Double DQN**：选动作用在线网络、估值用目标网络，治 Q 值过高估计
- **Dueling DQN**：Q = V(s) + A(s,a) 分流，状态好坏和动作好坏分开学
- **Prioritized Replay**：TD 误差大的样本多抽，提高样本效率

## 3. 策略梯度方法（Policy-based）

### REINFORCE（最原始）
直接对策略 π_θ 求梯度：∇J = E[ ∇log π(a|s) · G_t ]
问题：G_t 方差太大 → 引入 **baseline**（通常用 V(s)），变成
∇J = E[ ∇log π(a|s) · A(s,a) ]，这就是 **Actor-Critic**：
Actor（策略网络）出动作，Critic（价值网络）估优势。

### GAE（广义优势估计）
多步 TD 误差的指数加权平均，λ 调偏差-方差权衡：
λ=0 偏差大方差小（只看一步），λ=1 反之。PPO 默认 λ=0.95。

### PPO（论文[8]，我们 Phase 1 用过：`src/train_ppo_lander.py`）
核心：**重要性采样 + 裁剪**
```
ratio = π_new(a|s) / π_old(a|s)
L = min( ratio·A, clip(ratio, 1−ε, 1+ε)·A )    ε≈0.2
```
直觉：新策略相对旧策略的变化幅度被限制在 ±20%，
防止一次更新毁掉已学知识（和"学习率不能太大"同一哲学）。
另有 **KL 惩罚版** PPO（RLHF 里常用）。

### GRPO（DeepSeekMath 2024，论文[10]）
PPO 的简化版，为大模型 RL 设计：
- **不要 Critic**：同一个 prompt 采样 G 个回答，用**组内平均奖励当
  baseline**，优势 = (自己的奖励 − 组均值) / 组标准差
- 好处：省掉价值网络（LLM 场景 Critic 很难训且占显存）
- 目标里加 **KL(π_θ || π_ref)** 惩罚，防止偏离参考模型太远
- 和推荐里的"排序损失/对比学习"思想同源：**相对优劣 > 绝对分数**

## 4. RLHF 与大模型对齐（求职最热的部分）

### 标准三段式（InstructGPT，论文[9]）
1. **SFT**：人工标注示范，监督微调
2. **奖励模型（RM）**：人工对多个回答排序，训一个打分模型
   （Pairwise 排序损失 = Bradley-Terry 模型，和推荐里的 BPR 一样！）
3. **RL 优化**：PPO/GRPO 最大化 RM 打分，同时 KL 惩罚不偏离 SFT 模型

### DPO（Direct Preference Optimization）
不用 RL 的替代方案：从偏好数据直接推导闭式损失，等价于隐式 RM。
优点：简单稳定不用采样；缺点：离线方法、对分布外数据敏感。
面试常考：**PPO vs DPO 各自适用场景**。

### 常见坑
- **Reward hacking**：模型找到 RM 的漏洞刷分（比如输出变长）
  → 对策：KL 惩罚、RM 集成、定期重标数据
- **KL 散度方向**：RLHF 用 KL(π_θ||π_ref)，防"跑太远"

## 5. RL 在推荐系统中的应用（本项目主线）

| 层级 | 方法 | 优化目标 | 项目位置 |
|------|------|----------|----------|
| 无决策 | DeepFM 排序 | 单次点击概率 | `src/train_deepfm.py` |
| 单步 RL | Contextual Bandit (LinUCB) | 单次奖励 + 探索 | `src/run_bandit.py` |
| 多步 RL | DQN / DRN / SlateQ | 会话/长期留存 | Phase 2 模块 2 |

**为什么推荐需要多步 RL**：推一个"标题党"这次会点，但用户腻了会流失。
长期奖励 = 留存，必须用 γ 折扣的多步回报建模。

**离线 RL 的特殊困难**（面试亮点）：
- 日志数据有偏（旧策略只推过它敢推的）→ 反事实评估
- **IPS（逆倾向加权）**：用旧策略的打分概率纠偏
- 仿真器（用模型模拟用户）是折中方案，本课题采用

## 6. 高频面试题（自问自答清单）

1. Q-learning 和 SARSA 的区别？→ max vs 实际动作；off/on-policy
2. DQN 为什么要 target network？→ TD 目标里也有自己的参数，
  自己追自己会发散；延迟拷贝切断相关性
3. Replay buffer 为什么能稳训练？→ 去相关性 + 数据复用（off-policy）
4. PPO 的 clip 在防什么？ratio 是什么？→ 重要性采样权重；
  限制单步更新幅度，防止策略崩溃
5. GAE 的 λ 调什么？→ 优势估计的偏差-方差权衡
6. GRPO 相比 PPO 改了什么？为什么适合 LLM？→ 去 Critic、组内相对
  优势、KL 惩罚；LLM 的 Critic 难训且显存翻倍
7. 什么是 reward hacking？怎么缓解？
8. On-policy 为什么样本效率低？→ 数据用一次就过期（策略变了）
9. Bellman 最优方程和贝尔曼期望方程各是什么？
10. γ 取 0 和 1 分别意味着什么？→ 纯贪心单步 / 无限远视
11. Bandit 和完整 RL 的区别？→ 无状态转移，单步决策
12. RLHF 的 RM 用什么损失训？→ Pairwise 排序损失（Bradley-Terry）
