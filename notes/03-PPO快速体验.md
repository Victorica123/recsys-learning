# 学习日志 · RL 快速体验：PPO 学登月

> 日期：2026-07-18 ｜ 用时：约 40 分钟

## 本阶段目标
亲手跑通一个完整的 PPO 强化学习实验，建立"智能体-环境-奖励"的直觉，
为后面把推荐系统当 RL 环境做准备。

## 强化学习的核心概念（对照着记）

| 概念 | 本实验里是什么 | 类比推荐系统 |
|------|---------------|--------------|
| 智能体 Agent | PPO 策略网络（8维观测→4个动作概率） | 推荐模型 |
| 环境 Environment | LunarLander 物理仿真 | 用户 |
| 状态/观测 State | 位置、速度、角度、腿触地（8维） | 用户画像+历史行为 |
| 动作 Action | 熄火/左推/主推/右推 | 推荐哪个物品 |
| 奖励 Reward | 着陆+100 / 坠毁-100 / 点火微罚 | 点击/观看时长 |
| 回合 Episode | 一次完整降落 | 一次用户会话 |

## PPO 的三个关键词
1. **策略网络**：就是大脑。和我们推荐模型一样是神经网络，一样梯度下降训练
2. **优势估计（Advantage）**：这个动作比平均水平好多少？好的推概率、差的压概率
   —— GRPO 的"组内相对优势"就是这个思想的变体
3. **裁剪（Clip）**：每次只许小步更新，防止一步迈太大毁掉已学知识
   —— 和阶段 1 里"lr 太大导致过拟合崩溃"是同一个哲学

## 实验结果
- 16 个环境并行采样，共训练 **108 万步**（CPU 约 3.5 分钟）
- 平均奖励：-40（坠毁）→ 128（会落了）→ **255.6（超过 200 的"学会"线）**

## 踩坑记录
- `box2d-py` 在 Windows 上源码编译失败（缺 C++ 编译器），
  改装预编译的 `Box2D` 包解决
- SB3 加载模型时默认放回 GPU，但 MLP 小网络在 GPU 上反而慢 3 倍
  （数据搬运开销 > 计算收益），`PPO.load(..., device="cpu")` 强制回 CPU
